# 养老金

首版 0.1.0；整理日期 2026-10-01。金额/规则为注明日期的快照，回答时重新核实。行动建议与成本分档均属作者判断（C），不是法律或科研证据评级。来源 ID 见 sources.json。

## PENSION-01 · 三层养老金分开盘点

- 规则或问题：瑞典养老金由公共养老金、雇主职业养老金和个人储蓄等构成。
- 行动：分别读取公共养老金记录、各雇主职业养老金与私人资产；比较长期现金流。
- 成本：钱低；时间中；精力低
- 收益口径：金钱：发现缺失记录与退休缺口
- 条件与边界：退休年龄与不同领取项目须按出生年和当前规则核实。
- 来源：S07；D02 仅为汇总入口

## PENSION-02 · 新工作比较总报酬

- 规则或问题：多数工作提供职业养老金，但不能假设任何雇主都有相同保障。
- 行动：比较固定薪资、职业养老金、保险、休假和 kollektivavtal；要求雇主提供书面计划。
- 成本：钱低；时间中；精力低
- 收益口径：金钱/权益：比较 offer 实际价值
- 条件与边界：计划供款比例、工资门槛与离职后的保险延续需查具体方案。
- 来源：S07；合同事实须由雇主/计划机构确认

## PENSION-03 · löneväxling 先查影响

- 规则或问题：工资转养老金可能改变当前净收入、流动性及以工资为基础的待遇。
- 行动：查当年收入门槛、雇主补充供款、费用、保险与退出条件；比较领取时税负。
- 成本：钱：锁定流动性；时间中；精力中
- 收益口径：金钱：潜在长期净值，情境依赖
- 条件与边界：不固化“某工资以上必划算”；离职补偿换养老金与普通工资转换不能直接混同。
- 来源：作者分析 C；须追加 Pensionsmyndigheten、Skatteverket、雇主计划现行资料

## PENSION-04 · 中国养老金与瑞典待遇分项目核实

- 规则或问题：境外养老金对瑞典各养老金和补助项目的影响不同。
- 行动：披露境外养老金类型、金额与领取地，向 Pensionsmyndigheten 分项确认，并另核实税务。
- 成本：钱低至中；时间中；精力中
- 收益口径：权益/金钱：正确申报及预测
- 条件与边界：不能说所有瑞典养老金都减，也不能说全都不受影响。
- 来源：S07、S09、S10

## PENSION-05 · 领取时长与遗属保护一起比较

- 规则或问题：部分职业养老金有有限期或终身等领取安排，受计划条款影响。
- 行动：比较税后收入曲线、长寿情境、伴侣需要和受益人安排。
- 成本：钱：机会成本；时间中；精力中
- 收益口径：金钱/家庭：降低后期收入骤降
- 条件与边界：不默认提前领取划算；遗属保障有成本且并非所有人都适合。
- 来源：S07；具体计划规则需另查
