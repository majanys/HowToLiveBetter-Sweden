# How to Live Better · 瑞典版
### Swedish life decisions for Chinese-speaking residents

面向生活在瑞典的中文使用者的 AI 生活决策技能。**首版 v0.1.0 · 整理日期：2026-10-01**。

结合瑞典实际制度，帮助回答“值不值、怎么选、能申请什么、先做什么”。比较金钱、时间、精力、收益、风险与可逆性，并在回答时核实当前官方规则。

## 使用技能

完整技能目录为 [skills/sweden-life-guide](skills/sweden-life-guide)，入口是 [SKILL.md](skills/sweden-life-guide/SKILL.md)。

在支持 SKILL.md 的代理工具中，把完整目录安装到该工具规定的技能目录；具体路径以工具官方说明为准。公开版采用**显式调用**：安装后明确请求使用 `$sweden-life-guide`。单纯打开本仓库不等于安装。

若工具不支持技能，可提供 SKILL.md 和相关 references 文件并要求遵循其工作流，但这不等于系统级安装。需要联网检索能力核实现行规则；离线时只能提供框架与查证路径。

### 示例

- 使用 `$sweden-life-guide`：我离职后有补偿，想休息半年，SGI 和 a-kassa 要先做什么？
- 我在瑞典长期生活，中国银行利息要怎样核实申报义务？
- 比较 ISK、普通证券账户与银行存款的税负、风险和流动性。
- 与伴侣同居、共同买房，哪些产权和身后保障问题要核实？

## 规则核实与适用条件

区分国籍、居留身份、人口登记、税务居民及社保归属，不把它们当作同一资格。明确地区、收入年度、劳动关系结束日与跨境事实。

[来源登记](skills/sweden-life-guide/references/sources.json)记录官方链接、检索日期和已核实范围。金额、税率、福利条件、领取年龄、贷款和住房规则均须**使用时重新核实**。网页更新时间、规则生效日期与历史/过渡制度要分别处理。本项目不承诺自动监控法律变化。

规则权威性与建议证据质量分开标识；成本收益建议不是机构的个案决定。无法核实时明确说明，不捏造引用或保证资格。
